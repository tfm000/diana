| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Tampering | per-engine default voice from app_settings | mitigate | `resolve_default_voice` validates the remembered id against the live enumerated list before use; an absent id falls back to the engine default (D-03 / Pitfall 5) — a stale id is never fed to `say -v`. |
| T-03-12 | Denial of Service | re-shelling `say -v '?'` on every keystroke in the search box | mitigate | `@st.cache_data` wraps enumeration keyed by engine name (Pattern 6); the search box filters the cached in-memory list, not the subprocess. |

| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs NO packages. N/A. |
