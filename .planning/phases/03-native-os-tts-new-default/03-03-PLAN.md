<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| document text → `say` subprocess | Untrusted document chunk text crosses into a shell-capable binary |
| worker → temp WAV file | Synthesized audio written to a temp path then read back |
| stored config / job voice id → engine | A persisted/selected voice id is fed to synthesis |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering / Elevation | `_say_synth` document text → `say` | mitigate | List-argv `subprocess.run([...])`, never `shell=True`; `cmd.append(text)` so text is the final argv DATA element, never interpolated into a command string (V5). Copy `piper_engine.py:114-122`. |
| T-03-07 | Denial of Service | huge text / hung `say` process | mitigate | `timeout=300` on `subprocess.run` (Piper precedent); per-call text already bounded by `processing.chunk_max_chars`. |
| T-03-08 | Information Disclosure | temp WAV leakage/collision | mitigate | `tempfile.NamedTemporaryFile(suffix=".wav", delete=False)` + `finally: Path(tmp).unlink(missing_ok=True)` (V12); no predictable shared path. |
| T-03-09 | Tampering | untrusted voice id passed to `say -v` | mitigate | Voice id is appended as a discrete `-v <id>` argv element (not interpolated); selected ids are validated against the live enumerated list at the UI layer (Plan 04, Pitfall 5). Empty id => no `-v` (system default). |
| T-03-10 | Spoofing / Info Disclosure | unexpected cloud/network call | accept | The macOS path is a local subprocess only; no socket/network import in the engine — verified by `<verification>`. No external service. |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs NO packages (macOS `say` is OS-provided). winrt deps are gated to Plan 05. N/A here. |
</threat_model>
