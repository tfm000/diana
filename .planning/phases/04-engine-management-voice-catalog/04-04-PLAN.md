<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user upload / path entry -> filesystem | Untrusted filename + bytes cross here on manual import |
| user free-text (tags/search) -> matcher | Untrusted free-text drives filter/search |
| Diana -> HuggingFace CDN | Untrusted sample-clip bytes fetched on preview |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-PATH | Tampering | manual import filename (`../`, absolute, zip-slip) | mitigate | `safe_voice_dest`: os.path.basename + resolved-prefix-under-model_dir + `.onnx`/`.onnx.json` allow-list (Pattern 5 / HARD-03); reject otherwise |
| T-04-PAIR | Tampering | import of a mismatched/corrupt pair | mitigate | Require both files with a shared base; `.onnx.json` must parse as JSON before copy; clear rejection message |
| T-04-REDOS | Denial of Service | name-search free-text compiled as regex | mitigate | Reuse Phase-3 `_fold` + plain substring `in` — never compile user input as regex |
| T-04-MEMUP | Denial of Service | oversized upload into memory | mitigate | server.maxUploadSize bounds file_uploader (Pitfall 7); path-entry option sidesteps the cap for large local files |
| T-04-INT | Tampering | corrupt sample/voice fetch | mitigate | Inherited from Plan 02 downloader (md5 on voice files; samples are non-executable preview audio, low value); HTTPS + default TLS verify |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No package installs — all deps pre-existing and pinned; RESEARCH Package Legitimacy Audit clean |
</threat_model>
