<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Diana -> HuggingFace CDN | Untrusted bytes cross here on download/refresh (resumable GET + manifest fetch) |
| manifest JSON -> TTSVoice | Untrusted/remote JSON parsed into typed objects |
| download bytes -> on-disk model | Untrusted content finalized into the per-user cache |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-INT | Tampering | download_file finalize | mitigate | md5 verify of the completed `.part` against the manifest `md5_digest` before `os.replace`; delete `.part` on mismatch; never install an unverified file (Pattern 1) |
| T-04-DL | Tampering | resume append on Range-ignored 200 | mitigate | append ("ab") only on 206; reset offset + "wb" on 200, preventing a duplicated-prefix corrupt `.part` (Pitfall 2) |
| T-04-DISK | Denial of Service | unbounded download exhausting disk | mitigate | has_space gates every download (free >= needed*margin) and refuses before any bytes are written (D-05) |
| T-04-MEM | Denial of Service | loading a multi-GB file into memory | mitigate | `iter_content(chunk_size=1<<16)` streaming write — never `r.content` |
| T-04-TLS | Information disclosure / Tampering | MITM on download/manifest | mitigate | HTTPS URLs only; rely on requests' default TLS verification — never pass `verify=False` |
| T-04-AVAIL | Denial of Service (feature) | curated voice 404 / manifest drift | accept (graceful) | refresh_catalog falls back to the bundled snapshot on failure; download 404 surfaces a recoverable "try Refresh catalog" message; provenance commit pinned (Pitfall 6) |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No package installs — all deps pre-existing and pinned; RESEARCH Package Legitimacy Audit clean; no `[ASSUMED]`/`[SUS]` packages |
</threat_model>
