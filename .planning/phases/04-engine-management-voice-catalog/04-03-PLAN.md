<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Streamlit script thread <-> download thread | The spawned thread is untrusted to touch Streamlit; it may only write the shared `dl_state` dict |
| Diana -> HuggingFace CDN | Untrusted bytes downloaded into the per-user cache (handled by the Plan-02 downloader) |
| UI action -> filesystem | Install writes only under `paths.model_dir()` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-SRC | Information disclosure / crash | download thread calling st.* (ScriptRunContext leak) | mitigate | Thread writes only to `dl_state`; ALL st.* render from the script thread via the `@st.fragment` poller (RESEARCH Pattern 3 / Anti-Patterns) |
| T-04-RETRIG | Tampering (corrupt .part) | double-click / rerun spawning a second writer thread | mitigate | Guard on `dl_state[voice_id]` in-flight before spawning; serialize to one in-flight download (Pitfall 3) |
| T-04-DISK | Denial of Service | install exhausting disk | mitigate | `has_space` pre-check gates the Install button and refuses before any bytes are written (D-05) |
| T-04-WORKER | (architecture) | running a download inside JobWorker/pipeline | mitigate | Download is UI-triggered on a UI-spawned thread; `worker.py`/`pipeline.py` are NOT touched (ENGINE-04) |
| T-04-INT | Tampering | corrupt download installed | mitigate | Inherited from Plan 02: md5 verify before `os.replace`, delete `.part` on mismatch |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No package installs — all deps pre-existing and pinned; RESEARCH Package Legitimacy Audit clean |
</threat_model>
