<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user label/tag free-text -> storage + matcher | Untrusted free-text persisted to app_settings and used in filter/search |
| app_settings JSON -> TTSVoice merge | Stored JSON parsed and merged onto a voice |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-REDOS | Denial of Service | custom tags / name search compiled as regex | mitigate | Reuse Phase-3 `_fold` + plain substring `in` for tags and name search — never compile user-supplied free-text as a regex |
| T-04-LBLJSON | Tampering | malformed stored label JSON crashing the browser | mitigate | get_label_overrides tolerates absent/empty (returns {}); apply_overrides only replaces known fields and is a no-op when empty — a bad value cannot crash enumeration |
| T-04-NOIMPORT | (architecture / ENGINE-01) | badge path importing a heavy SDK | mitigate | Badges use the install_state filesystem probe only; no onnxruntime/piper/kokoro import on the Upload render path |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No package installs — all deps pre-existing and pinned; RESEARCH Package Legitimacy Audit clean |
</threat_model>
