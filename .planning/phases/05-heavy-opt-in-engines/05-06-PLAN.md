## Phase Goal

**As a** power user, **I want to** add my own reference voice (by uploading a clip + transcript or recording in-app), **so that** F5 can clone it and narrate my documents in that voice.

This slice completes HEAVY-02 with the reusable, engine-agnostic Custom Voices library (D-11..D-14). It builds on 05-05's F5 (which already synthesizes with a bundled default voice): now a user can save named custom voices, which appear in the F5 picker AND the cross-engine browser, are reusable and removable, and drive F5 cloning. The library is one shared pool — built for F5 today and reused by Fish in 05-07 and any future cloning engine.

Validation (D-13) reuses Phase-4's reject-with-a-message discipline (never crash) and `soundfile.info()` for duration/samplerate. Path safety reuses `catalog.safe_voice_dest`'s basename + allow-list + containment. Metadata reuses the `voice_labels` app_settings pattern. The custom voices flow through the existing `all_engine_voices` cross-engine browser automatically once `get_engine_voices("f5")` becomes dynamic.

Purpose: deliver F5 reference-audio cloning + the reusable capture/upload library.
Output: Custom Voices section live; `test_custom_voices` green; UI human-verified.
