Purpose: a clean substrate that keeps D-02 (base install untouched) true and makes the engine slices thin.
Output: GPU probe + install-state + registry helpers green against the Wave-0 scaffolds (`test_gpu_probe`, `test_install_state_heavy`, `test_heavy_failfast`).
